# Notifications

Simple overview: what notifications exist, who receives them, and when they are sent.

| Notification | Who receives it | When it is sent |
|--------------|-----------------|------------------|
| **CAPA assigned** | The user who was assigned | Someone assigns that user to a CAPA |
| **CAPA unassigned** | The user who was unassigned | Someone removes that user from a CAPA |
| **CAPA action assigned** | The user who was assigned | Someone assigns that user to a corrective/preventive action item on a CAPA |
| **CAPA action unassigned** | The user who was unassigned | Someone removes that user from a corrective/preventive action item on a CAPA |
| **CAPA evidence attached** | All users assigned to the CAPA (except the one who attached) | Someone attaches evidence/documents to the CAPA |
| **Tool assigned** | The user who was assigned | A company admin assigns that user to a tool (subcheckpoint) |
| **Tool unassigned** | The user who was unassigned | A company admin removes that user from a tool |
| **Assignment evaluated** | Users linked to the same assignment + company admins (except the evaluator) | An assignment is evaluated (e.g. approved or rejected) |

Users can turn email notifications on or off in **Settings → Platform settings → Email notifications**. When on, they also receive an email for each in-app notification.
